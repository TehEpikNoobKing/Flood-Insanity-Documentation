Getting Started

Welcome to Flood Insanity map making! This page will guide you through installation of the Map Development Kit, and the basic features that come included.

Installation

Installation is very simple. Just follow the basic instructions, and hope nothing blows up along the way, yeah?

1) GET the Map Development Kit using the link below.

Map Development Kit

2) Open up a brand new place on Vortex Studio.

3) Insert the model into the place.

4) You've now installed the map kit! No extra steps are required.
