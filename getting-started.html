Getting Started

Welcome to Flood Insanity map making! This page will guide you through installation of the Map Development Kit, and the basic features that come included.

Installation

Installation is very simple. Just follow the basic instructions, and hope nothing blows up along the way, yeah?

What you need:

  • The Map Development Kit (linked below)
  • Vortex Studio (v0.8+)

Instructions:

  1. Get the map development kit.
  2. Open up the place on Vortex Studio.
  3. That's it. Yay!
Get the Map Development Kit

_Spawn Required

_Spawn is where the players first load into the map. The _Spawn part is usually 12x1x12 studs large, however it can be any size. Their character and their camera both face the FRONT surface of the part, so making the faces different from each other can be a good idea, which is already done through the Map Kit.

_Exit Required

_Exit is where the part region where the players must reach to survive the map, and is only enabled when all the Buttons in the map have been pressed. _Exit can be resized to be any region where the players' goal is, but it must be CanCollide false.

_ExitBlock

_ExitBlock(s) are parts that block off the Exit. These should also be CanCollide false, since they only become solid when a player survives.

These part(s) are optional, and are not required for the map to function.

ThumbnailCamera

ThumbnailCamera is a part that the player's camera locks onto during the loading screen, having a small swaying animation. This part can be anywhere with any size, but the camera is pointed from the center of the part, facing forward towards the front surface. It's advised to set this part to be transparent and CanCollide false, so that players don't notice it during gameplay.

This part is also optional, and is not required for the map to function.
