Publishing and FI-MTP

This page will guide you on how to navigate the Map Test Place's UI, and how to publish your map in order to be playable.

Flood Insanity Map Test Place

Multiplayer Servers

When first joining the Map Test Place, you will be in a Singleplayer server. In order to go to a Multiplayer server, you have two options:

  • Private Servers
  • The Server system

Private Servers are a good and very fast way of making a multiplayer server. However, it only allows players on the Owner's friend list, making it limiting for certain events.

The Server system allows players to create multiplayer servers and share them via a code, allowing for less limiting events of up to 50 players.

Map Test Panel

The Panel is the main way of interacting with the MTP. It allows for loading, removing, publishing and searching of maps, as well as creation of multiplayer servers, debug and fun options, and more! It's the main hub of the game, intergrated in the main menu.

Map List

_Exit Required

_Exit is where the part region where the players must reach to survive the map, and is only enabled when all the Buttons in the map have been pressed. _Exit can be resized to be any region where the players' goal is, but it must be CanCollide false.

_ExitBlock

_ExitBlock(s) are parts that block off the Exit. These should also be CanCollide false, since they only become solid when a player survives.

These part(s) are optional, and are not required for the map to function.

ThumbnailCamera

ThumbnailCamera is a part that the player's camera locks onto during the loading screen, having a small swaying animation. This part can be anywhere with any size, but the camera is pointed from the center of the part, facing forward towards the front surface. It's advised to set this part to be transparent and CanCollide false, so that players don't notice it during gameplay.

This part is also optional, and is not required for the map to function.
